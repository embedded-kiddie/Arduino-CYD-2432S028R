# 日本語フォントのサンプルビューワー

## 動作条件

### ハードウェア

  - ESP32-2430S028R (Cheap Yellow Display)

| Arduino IDE             | [2.3.4 (CLI 1.1.1)][10]      |
| ESP32 by Espressf       | [3.2.0 (ESP-IDF v5.4.1)][11] |
| LittleFS                | [同上][11]                   |
| arduino-littlefs-upload | [1.5.4][12]                  |
