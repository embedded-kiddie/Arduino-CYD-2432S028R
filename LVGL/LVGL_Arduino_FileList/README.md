# LVGL sample - File Selection List
A sample UI for collapsing folders like Explorer on Windows or Finder on Mac

## Environment
| Software components        | Version                                           |
| -------------------------- | ------------------------------------------------- |
| Arduino IDE                | [Version 2.3.4][1]                                |
| esp32 by Espressif Systems | [v3.2.1][2] or [v3.3.0][3]                        |
| Platform type              | [ESP32 Dev Module][4] or [ESP32-2432S028R CYD][5] |
| LVGL                       | [v9.2.2][6] or [v9.3.0][7]                        |
| LovyanGFX                  | [1.2.7][8]                                        |
| SD card library            | [SD][9] or [SdFat 2.3.0][10]                      |
